# iron-tui
TUI application for logging workouts without any bloat or having to be on your phone in the gym

## Stack

* Python
* Textual
* SQLite

## Core

* Show today's workout
* Show target weights/reps
* Log completed/failed lifts
* Track bodyweight and measurements
* Show strength and weight progress

## Screens

* Today
* Log
* Body
* Progress
* History

## Principles

* Keyboard-first
* Local-only
* Fast
* Minimal

## V1

1. Define workouts
2. Show today's workout
3. Log results
4. Save to SQLite
5. View history
6. Track bodyweight

Launch with:

```bash
iron
```

Goal: open the app, immediately see what to lift, and log a workout in seconds.
